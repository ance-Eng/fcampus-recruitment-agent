# 校园实习招聘岗位能力标准

## Java 后端开发实习生

### 核心能力要求
1. 熟练掌握 Java 基础语法，理解面向对象编程思想
2. 熟悉 Spring Boot / Spring MVC 框架，能独立开发 RESTful 接口
3. 熟悉 MySQL 数据库，能编写复杂 SQL，了解索引优化
4. 了解 Redis 缓存的基本使用场景
5. 熟悉 Git 版本控制和 Maven 项目管理
6. 了解 Linux 基本操作命令

### 加分项
- 有 MyBatis / MyBatis-Plus 使用经验
- 了解微服务架构（Spring Cloud）
- 了解消息队列（RabbitMQ / Kafka）
- 有高并发、分布式系统实践经验
- 熟悉 JVM 调优

### 考察重点
- 数据结构与算法基础
- Java 集合框架（HashMap、ArrayList 原理）
- 多线程与并发（synchronized、Lock、线程池）
- Spring IOC / AOP 原理
- 数据库事务与索引

---

## Python 开发实习生

### 核心能力要求
1. 熟练掌握 Python 基础语法和常用标准库
2. 熟悉 Django 或 Flask 至少一种 Web 框架
3. 熟悉 MySQL / PostgreSQL 数据库
4. 了解 RESTful API 设计
5. 熟悉 Git 和 Linux 基本操作

### 加分项
- 有爬虫开发经验（Scrapy / Requests）
- 了解异步编程（asyncio / aiohttp）
- 熟悉 Docker 容器化部署
- 有数据分析处理经验（Pandas / NumPy）
- 了解 Celery 任务队列

### 考察重点
- Python 装饰器、生成器、迭代器
- GIL 与多线程/多进程
- Web 框架请求处理流程
- 数据库 ORM 使用
- 代码规范与工程化

---

## 前端开发实习生

### 核心能力要求
1. 熟练掌握 HTML5、CSS3、JavaScript（ES6+）
2. 熟悉 Vue.js 或 React 至少一种主流框架
3. 了解 HTTP 协议和浏览器原理
4. 熟悉 Git 工作流

### 加分项
- 熟悉 TypeScript
- 了解 Webpack / Vite 构建工具
- 有小程序开发经验
- 了解前端性能优化
- 熟悉 Node.js 后端开发

### 考察重点
- JavaScript 原型链、闭包、作用域
- 框架响应式原理
- CSS 布局（Flex / Grid）
- 跨域解决方案
- 浏览器渲染机制

## 数据分析实习生

### 核心能力要求
1. 熟练使用 SQL 进行数据查询和统计
2. 熟练使用 Excel（数据透视表、VLOOKUP 等）
3. 熟悉 Python 数据处理（Pandas / NumPy）
4. 了解基本统计学知识
5. 具备数据可视化能力

### 加分项
- 熟悉 Tableau / Power BI
- 了解机器学习基础算法
- 有 Hive / Spark 大数据处理经验
- 熟悉 A/B 测试设计
- 有业务分析报告撰写经验

### 考察重点
- SQL 复杂查询（窗口函数、多表关联）
- 数据清洗与处理能力
- 指标体系搭建思维
- 业务理解与分析框架
- 数据可视化表达

- 熟悉抓包工具（Fiddler / Charles）

### 考察重点

- Bug 定位与分析能力

## 运维开发实习生

### 核心能力要求
1. 熟悉 Linux 系统管理和 Shell 脚本
2. 熟悉 Python 或 Go 至少一种编程语言
3. 了解 Docker 容器技术
4. 熟悉 TCP/IP 网络基础
5. 了解 Nginx / Apache Web 服务器

### 加分项
- 熟悉 Kubernetes（K8s）编排
- 了解 Jenkins CI/CD 流水线
- 熟悉监控系统（Prometheus / Zabbix）
- 了解 Ansible 自动化运维
- 有云平台使用经验（阿里云 / AWS）

### 考察重点
- Linux 系统原理与常用命令
- 网络协议与排障能力
- Shell / Python 脚本编写
- 容器化与编排理解
- 故障排查与应急响应思维
