# 校园招聘面试题库

## 通用面试问题

### 自我介绍类
1. 请用三分钟做一个自我介绍
2. 你为什么选择我们公司这个岗位？
3. 你觉得自己最大的优势和劣势是什么？
4. 你的职业规划是什么？三到五年内想达到什么水平？
5. 你在学习或项目中遇到的最大困难是什么？怎么解决的？

### 综合素质类
1. 描述一次你与团队成员意见不合的经历，你是怎么处理的？
2. 如果同时有多个任务截止时间很近，你会怎么安排？
3. 你平时通过什么方式学习新技术？
4. 你对加班怎么看？
5. 你有什么问题想问我们？
