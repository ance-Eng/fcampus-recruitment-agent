# 技术栈能力评估参考

## 编程语言能力等级

### Java
- 入门级：掌握基础语法、面向对象、集合框架基本使用
- 进阶级：理解 JVM 内存模型、多线程并发、IO/NIO、反射注解
- 熟练级：熟悉 JVM 调优、并发包源码、JVM 类加载机制、性能优化

### Python
- 入门级：掌握基础语法、数据结构、函数、文件操作
- 进阶级：理解装饰器、生成器、上下文管理器、多线程多进程
- 熟练级：熟悉异步编程、元类、内存管理、C 扩展、性能调优

### JavaScript
- 入门级：掌握基础语法、DOM 操作、事件处理
- 进阶级：理解原型链、闭包、异步编程、ES6+ 新特性
- 熟练级：熟悉 V8 引擎原理、函数式编程、设计模式、工程化

## 框架熟练度评估

### Spring Boot
- 了解：知道是什么，能用它跑起一个 Hello World
- 熟悉：能独立开发 CRUD 接口，理解自动配置，会整合 MyBatis/Redis
- 精通：理解 Starter 原理、自动配置源码、能自定义 Starter，熟悉源码

### Vue / React
- 了解：能写基本组件，理解数据绑定
- 熟悉：能独立开发完整页面，理解组件通信、生命周期、状态管理
- 精通：理解响应式原理、虚拟 DOM diff 算法、能做性能优化和架构设计

### Django / Flask
- 了解：能搭建基础项目，写简单视图
- 熟悉：理解 ORM、中间件、路由系统，能开发完整后端
- 精通：理解请求处理流程源码，能做性能优化、安全加固

## 数据库能力评估

### MySQL
- 入门：会写基本 CRUD SQL，知道表的创建
- 熟练：会写多表关联、子查询、聚合函数，理解索引基本原理
- 精通：理解索引底层结构、事务隔离级别实现、锁机制、能做 SQL 优化和分库分表

### Redis
- 入门：知道五种基本数据类型，会做简单缓存
- 熟练：理解持久化机制、过期策略、能解决缓存常见问题
- 精通：理解集群方案、分布式锁实现、能做高可用架构设计

## 项目经验评估维度

1. **技术深度**：项目中使用的技术是否理解原理，还是只会调用 API
2. **业务理解**：是否清楚项目解决了什么问题，业务价值是什么
3. **个人贡献**：在项目中承担了什么角色，独立完成了哪些模块
4. **问题解决**：遇到过什么技术难点，如何分析和解决的
5. **工程规范**：代码质量、文档、测试、版本控制是否规范
6. **复盘能力**：项目结束后有什么总结，下次会怎么改进

## 学历与院校参考

### 技术岗学历要求
- 大厂核心研发：硕士优先，本科 985/211
- 大厂普通研发：本科及以上，重点院校优先
- 中小公司研发：本科及以上，能力为主
- 测试/运维/数据：大专及以上，本科优先

### 实习转正概率
- 有相关实习经历：转正概率显著提升
- 实习期间表现优秀：约 60%-80% 可转正
- 无实习经历：需通过完整面试流程
