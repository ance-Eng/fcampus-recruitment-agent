# 金融岗位能力标准

## 银行管培生

### 核心能力要求
- 金融、经济、会计等相关专业本科及以上学历
- 熟悉银行业务基础知识：存贷款、结算、理财
- 具备数据分析能力，熟练使用Excel
- 沟通表达能力强，有服务意识
- 持有CFA、FRM、银行从业资格证优先

### 面试考察重点
- 对金融行业的理解
- 数据分析能力
- 沟通表达能力
- 抗压能力

### 常见面试题
- 为什么选择银行业？
- 如何看待当前宏观经济形势对银行业的影响？
- 客户投诉如何处理？
- 你的职业规划是什么？

## 证券分析师

### 核心能力要求
- 金融、经济、数学等相关专业硕士及以上学历
- 具备财务分析能力，能独立撰写研究报告
- 熟练使用Wind、Choice等金融数据终端
- 持有CFA优先
- 英语读写能力强

## 会计/审计

### 核心能力要求
- 会计、财务相关专业本科及以上学历
- 熟悉会计准则和税法
- 熟练使用财务软件和Excel
- 持有CPA、初级会计职称优先
- 细心严谨，有责任心

## 保险精算

### 核心能力要求
- 数学、统计、精算等相关专业本科及以上学历
- 具备扎实的数学和统计基础
- 熟悉保险产品定价原理
- 持有精算师考试科目通过证明优先
