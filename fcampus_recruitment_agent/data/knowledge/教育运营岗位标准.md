# 教育与运营岗位能力标准

## 教师岗位

### 核心能力要求
- 师范类专业本科及以上学历，持有教师资格证
- 具备扎实的学科专业知识
- 掌握教学设计和课堂管理能力
- 沟通表达能力强，有耐心
- 了解教育心理学

### 面试考察重点
- 试讲表现（教学设计、表达能力）
- 学科专业知识
- 班级管理能力
- 教育理念

### 常见面试题
- 如何设计一堂课？
- 遇到调皮学生怎么处理？
- 你对"双减"政策怎么看？
- 为什么选择当老师？

## 运营专员

### 核心能力要求
- 市场营销、新闻传播等相关专业本科及以上学历
- 具备内容策划和活动运营能力
- 熟练使用Office、PS等工具
- 数据分析能力强
- 网感好，熟悉社交媒体平台

### 面试考察重点
- 运营思维和创意能力
- 数据分析能力
- 项目执行能力
- 对平台规则的了解

### 常见面试题
- 介绍一个你策划的运营活动
- 如何提升用户留存率？
- 数据下降时如何分析原因？
- 你常用哪些内容平台？

## 产品经理

### 核心能力要求
- 计算机、市场营销等相关专业本科及以上学历
- 具备需求分析和产品设计能力
- 熟练使用Axure、墨刀等原型工具
- 数据分析能力强
- 沟通协调能力强

## 人力资源

### 核心能力要求
- 人力资源管理、心理学等相关专业本科及以上学历
- 熟悉招聘、培训、绩效等HR模块
- 沟通表达能力强
- 持有企业人力资源管理师证书优先
- 细心严谨，有亲和力
